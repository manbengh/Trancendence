# ft_transcendence

## About

ft_transcendence is a full-stack web application developed as part of the 42 curriculum. It consists of building a social platform with real-time features, user interactions and a secure backend API.

## Features

- User profiles and social interactions.
- Friend requests, friend lists and mutual friend suggestions.
- Notifications with read and delete options.
- Public REST API with API key authentication and rate limiting.
- Post management (CRUD operations).
- API documentation using Swagger.
- Input validation and centralized error handling.

## Technologies

- **Languages:** JavaScript, SQL
- **Frontend:** Next.js
- **Backend:** Node.js
- **Database:** PostgreSQL
- **ORM:** Prisma
- **Tools:** Docker, Docker Compose, Swagger, Git
